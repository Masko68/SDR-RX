Deze repository bevat bewust GEEN binaire stuurprogramma's uit Mykola FREE.

Voor Airspy R2 ontvangst: kopieer de volgende DLLs uit je bestaande, werkende
Mykola-20VFO-Audiofix-Python314\drivers\ map naar deze drivers\ map:

- airspy.dll
- libusb-1.0.dll
- pthreadVC2.dll
- msvcr100.dll

Gebruik alleen DLLs waarvan je de distributie- en gebruiksrechten hebt geverifieerd.
Je bestaande scannerinstallatie hoeft voor GitHub niet te worden gewijzigd.
